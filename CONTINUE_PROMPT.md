# CONTINUE PROMPT (TPP)

Продолжай работу по проекту из текущего состояния.

**Чеклист старта (7 пунктов):** `START_CHECKLIST.md`. Подробности — `AGENT_WORKFLOW.md`. Кратко (сначала контекст, потом обзор при необходимости):
1) Прочитай `HANDOFF.md` (если файла нет — создай в корне репозитория минимальную структуру: назначение, **ACTIVE**, пустой **Лог шагов**; см. `docs/handoff-conventions.md`). История: дописывание в конец лога, без перезаписи старых шагов.
2) Прочитай `TASKS.md` (список задач; статус сверяй с `HANDOFF.md` и фактическим состоянием).
3) Прочитай `Проект Проектов/subagent-orchestration-policy.md` и соблюдай его.
4) Предстартовый обзор проекта — **после** п.1–3: полный или облегчённый по критериям `AGENT_WORKFLOW.md` (если в логе уже есть актуальный обзор или выполнены условия облегчённого старта — не дублировать без причины); зафиксировать в `HANDOFF.md` при новом обзоре или при облегчённом старте — кратко почему обзор сокращён.
5) При первом знакомстве с форматом шагов — `docs/handoff-conventions.md` (можно не перечитывать каждый чат, если формат уже усвоен).

Правила продолжения:
- Перед запуском приложения (или шагом со сборкой/тестами/dev-сервером) проверь **среду**: инструменты, при необходимости плагины IDE, драйверы/сервисы по документации проекта (подробно — `AGENT_WORKFLOW.md`, раздел «Проверка среды для запуска приложения»). Если всё ок — отдельно не отчитывайся; если чего-то нет — предложи пользователю доустановить/настроить.
- Источник текущего состояния: `HANDOFF.md`; для быстрого фокуса — строка **ACTIVE** в блоке «Якорь ACTIVE» (её **можно** обновлять одной строкой при смене задачи; остальные блоки шапки — по правилам ниже).
- Запись в **Лог шагов** — по правилам **логического шага** и **микрошагов** в `docs/handoff-conventions.md` (не обязательно после каждой мелкой правки).
- Если в рамках шага **создан новый файл** (документ, отчёт, чек-лист и т.п.), в этом же шаге обязательно укажи **относительный путь от корня репозитория** к файлу (см. `docs/handoff-conventions.md`).
- Если задача завершена, выбери следующую по приоритету из `TASKS.md` и зафиксируй переход новым шагом в конце **Лог шагов** в `HANDOFF.md` (не переписывая блоки «Текущий статус задачи» и «Следующий шаг» без договорённости с пользователем); обнови строку **ACTIVE** под новый фокус.
- Запрещено менять или переписывать существующие **шаги** в **Лог шагов** и блоки **`Текущий статус задачи`** / **`Следующий шаг`** (кроме явной договорённости с пользователем): допускается только новый шаг в конце лога и **обновление одной строки `ACTIVE`** в блоке «Якорь ACTIVE».
