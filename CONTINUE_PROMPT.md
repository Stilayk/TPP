# CONTINUE PROMPT (TPP)

Продолжай работу по проекту из текущего состояния.

Обязательный порядок перед любыми изменениями:
0) Сначала запусти отдельного агента или несколько агентов для обзора всего проекта и зафиксируй в ответе: что делает проект, на чем собран (стек), ключевые модули и текущее состояние.
1) Прочитай `HANDOFF.md` (это история; только дописывание в конец, без перезаписи/редактирования существующего содержимого).
2) Прочитай `TASKS.md` (это список задач; статус задач определяй по `HANDOFF.md` и фактическому состоянию проекта).
3) Прочитай `Проект Проектов/subagent-orchestration-policy.md` и соблюдай его.

Правила продолжения:
- Источник текущего состояния: `HANDOFF.md`.
- После каждого значимого шага дописывай новую запись в конец `HANDOFF.md` (`Задача` / `Время` / `Кто исполнил` / `Как исполнил`, плюс `Результат`).
- Если в рамках шага **создан новый файл** (документ, отчёт, чек-лист и т.п.), в этом же шаге обязательно укажи **относительный путь от корня репозитория** к файлу (см. `Проект Проектов/subagent-orchestration-policy.md`, раздел 5.3).
- Если задача завершена, выбери следующую по приоритету из `TASKS.md` и зафиксируй переход новым шагом в конце **Лог шагов** в `HANDOFF.md` (не переписывая блоки «Текущий статус задачи» и «Следующий шаг»).
- Запрещено менять или переписывать существующие разделы/записи в `HANDOFF.md` (включая `Текущий статус задачи` и `Следующий шаг`): допускается только новый шаг в конце лога.
