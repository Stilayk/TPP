# Инструкция по развертыванию и запрос ТЗ

## 1) Быстрый деплой через Docker Compose

### Предусловия
- Установлен Docker Desktop (или Docker Engine + Compose v2).
- Открыт доступ к порту `80`.

### Подготовка
1. Перейти в папку проекта `Проект Проектов`.
2. Создать файл `.env` (если отсутствует) и при необходимости указать секрет:
   - `N8N_WEBHOOK_URL=https://...` (опционально; для webhook-уведомлений).

### Запуск
1. Выполнить:
   - `docker compose up -d --build`
2. Проверить, что сервисы поднялись:
   - `docker compose ps`
3. Открыть приложение:
   - [http://localhost](http://localhost)

### Остановка и обновление
- Остановка: `docker compose down`
- Пересборка после изменений: `docker compose up -d --build`

### Данные и файлы
- SQLite хранится в `./data/app.sqlite` (volume `./data:/data`).
- Excel-экспорты хранятся в `./exports` (volume `./exports:/exports`).

## 2) Локальный режим разработки (без Docker)

1. Запустить backend на `127.0.0.1:8000`.
2. В корне проекта `Проект Проектов` запустить прокси:
   - `python local_dev_proxy.py`
3. Открыть:
   - [http://127.0.0.1:8080](http://127.0.0.1:8080)

## 3) Чек-лист запроса формального ТЗ

Перед запуском новых крупных задач запросить у заказчика:
- Цель фичи (какая бизнес-проблема решается).
- Роли и права доступа (кто что может делать).
- Подробный happy-path сценарий пользователя.
- Ограничения и edge cases (минимум 3 критичных).
- Критерии приемки в формате "дано/когда/тогда".
- Требования к данным (что хранить, срок хранения, кто видит).
- Требования к интеграциям (внешние сервисы, webhook, форматы).
- Нефункциональные требования (производительность, безопасность, аудит).
- План релиза (дата, окно, откат, ответственный).

## 4) Короткий шаблон запроса ТЗ

```text
Нужен формальный ТЗ для задачи: <название>.

Просьба заполнить:
1. Бизнес-цель:
2. Пользовательские роли и права:
3. Сценарий happy-path (шаги):
4. Критичные ограничения/исключения:
5. Критерии приемки:
6. Интеграции и внешние зависимости:
7. Требования к хранению/доступу к данным:
8. Дедлайн и план внедрения:
```
