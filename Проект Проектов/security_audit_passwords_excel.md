# P1 №15: Аудит хранения паролей и Excel

Документ восстановлен в репозитории (ранее отсутствовал в git). Выводы соответствуют текущему коду `backend/app/main.py` и конфигурации.

## Пароли

- **Хранение:** в SQLite, таблица `users`, поле `password_hash` (строка).
- **Алгоритм:** `passlib` с **`bcrypt`** (`CryptContext(schemes=["bcrypt"], deprecated="auto")`).
- **Проверка/смена:** пароли никогда не логируются в открытом виде в этом модуле; при логине и смене пароля используется `verify_password` / `hash_password`.
- **Вывод:** хранение паролей соответствует ожидаемой практике (хеш, не plaintext). Рекомендации эксплуатации: задать сильный `SESSION_SECRET`, ограничить доступ к файлу БД и бэкапам.

## Excel-отчёты

- **Каталог:** `EXPORTS_DIR` (по умолчанию `exports`, относительно рабочей директории процесса; в Docker — том, см. `docker-compose.yml`).
- **Имена файлов:** шаблон `report_{id}_{YYYY-MM-DD}.xlsx`, валидация через `EXPORT_FILENAME_RE`.
- **Доступ по HTTP:** `GET /exports/{filename}` — только роль **`admin`**, отчёт в статусе **`final`**, защита от path traversal (путь внутри `exports_dir()`).
- **Генерация:** `openpyxl`, файлы создаются на диске при финализации/скачивании при необходимости.
- **Вывод:** выдача Excel ограничена админом; файлы лежат на сервере в каталоге экспорта — нужны права ОС/резервного копирования на этот каталог.
