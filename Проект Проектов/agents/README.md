# Каталог сабагентов по технической документации

Этот каталог содержит спецификации сабагентов для подготовки технической документации в рамках системы ролевых агентов.

## Подключение политики оркестрации

Все сабагенты в этом каталоге обязаны выполнять общие требования оркестрации из файла `subagent-orchestration-policy.md`, включая:
- handoff через файлы-отчёты в `reports/{session_id}/`
- соблюдение лимитов повторных попыток и поведения при ошибках
- прозрачность через аудит-лог метаданных отчётов

Политика оркестрации:
`subagent-orchestration-policy.md` (в корне проекта)
