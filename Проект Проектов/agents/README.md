# Каталог субагентов по технической документации

Этот каталог содержит спецификации субагентов для подготовки технической документации в рамках системы ролевых агентов.

## Подключение политики и процесса

Субагенты обязаны выполнять:

- **`Проект Проектов/subagent-orchestration-policy.md`** — типы оркестрации, handoff, ретраи, логирование.
- **`AGENT_WORKFLOW.md`** (корень репозитория TPP) — старт чата, обзор, DoR/DoD.
- **`docs/handoff-conventions.md`** — поля записи в `HANDOFF.md`, пути к новым файлам.

Дополнительно по сценарию: handoff через файлы-отчёты в `reports/{session_id}/`, лимиты повторных попыток, прозрачность через метаданные отчётов — см. политику и профиль конкретного субагента.
