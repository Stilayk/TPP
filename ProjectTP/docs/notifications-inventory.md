# Уведомления: инвентаризация (P2 №26)

Документ фиксирует **текущие** каналы и триггеры. Интеграция с **Битрикс24** по графику и сообщениям в чат — **№22** (выполнено, см. `TASKS.md`); почасовой сценарий «кто дежурит» — по-прежнему **внешняя** настройка (cron / n8n), не жёстко в коде приложения.

## Почасовые и прочие сценарии в Битрикс (эксплуатация)

| Тот же вебхук / тот же чат | **Почасово** «кто дежурит» — вызов API или скрипта по расписанию **вне** репозитория (cron, n8n, агент ОС) | Не дублировать тот же текст параллельно в n8n/Telegram без явного решения (см. правила ниже). |

## Правила против «двойного спама»

1. Один сценарий (например «кто дежурит в следующем слоте») — **один исходящий канал** или чёткое разделение аудиторий (например n8n → только дежурный, Битрикс → общий канал).
2. Пока `N8N_WEBHOOK_URL` пустой, внешняя цепочка через n8n **молчит** — это штатный режим «отключено».
3. При изменении каналов Битрикс обновить этот файл: что удалено/оставлено в коде и env.
