# Стартовый чеклист агента (TPP)

Выполни по порядку перед изменениями в репозитории (детали — `AGENT_WORKFLOW.md`, `CONTINUE_PROMPT.md`).

1. **`HANDOFF.md`** — блок **ACTIVE**, **Текущий статус**, **Следующий шаг**, последние шаги **Лог шагов** (если файла нет — создай минимальный по `docs/handoff-conventions.md` + пустой лог).
2. **`TASKS.md`** — приоритет, критерий готовности, зависимости выбранной задачи.
3. **`Проект Проектов/subagent-orchestration-policy.md`** — политика оркестрации и handoff.
4. **Обзор проекта** — полный или облегчённый по `AGENT_WORKFLOW.md`; не дублировать без причины.
5. **При необходимости** — `docs/handoff-conventions.md` (формат шага, микрошаги, **ACTIVE**).
6. **Перед запуском приложения** — проверка среды (`AGENT_WORKFLOW.md`, раздел про инструменты/драйверы).
7. **Опционально:** `python scripts/check_agent_context.py` — файлы на месте и свежесть лога.
