- **Статус:** В очереди

### 33) Инструкция при выходе: QR-код на публичную страницу с текстом
- **Приоритет:** P2
- **Статус:** В очереди
- **Описание:** В модальном окне «Выход сотрудника» после формирования инструкции добавить действие (кнопка), которое выдаёт **QR-код** (превью в UI и **скачивание файла изображения**, например PNG, чтобы **распечатать** QR). При сканировании открывается **URL** в браузере; по нему отображается **тот же сформированный текст** инструкции (read-only HTML). Текст инструкции хранится на сервере под **неугадываемым токеном** с настраиваемым **TTL** (срок жизни ссылки; после истечения страница недоступна, сам QR как картинка остаётся прежним). Учесть, что ссылка по сути публичная — осознанный риск для строк с паролями (как при пересылке docx).
- **Критерий готовности:** Happy-path: сформировал инструкцию → получил QR → **скачал изображение** (для печати) → отсканировал с телефона → виден тот же текст; после TTL запись не отдаётся; базовый smoke или ручной чек-лист в `HANDOFF.md`; при появлении новых файлов — строка **Артефакт:** в этой карточке.
- **Зависимости:** Задача 13 (текущий конструктор и API инструкции)
