# ЗАДАЧИ

Легенда: `P1` - критично, `P2` - важно, `P3` - опционально/улучшение.

## Бэклог

## P1 - Критично

### 1) Админ: редактирование пользователей
- **Приоритет:** P1
- **Описание:** Добавить операции администратора: удаление пользователя, сброс/смена пароля, удаление истории отчетов пользователя.
- **Критерий готовности:** Админ может выполнить все 3 операции из UI и API с проверкой роли.
- **Зависимости:** Нет

### 2) Пользователь: смена собственного пароля
- **Приоритет:** P1
- **Описание:** Добавить возможность для обычного пользователя менять свой пароль в личных настройках.
- **Критерий готовности:** Пользователь успешно меняет пароль после проверки старого пароля.
- **Зависимости:** Задача 1 (общая логика обновления пароля, опционально)

### 3) Пометка неактивных дежурных
- **Приоритет:** P1
- **Описание:** Дать администратору возможность помечать сотрудников как неактивных/отсутствующих, чтобы генератор исключал их из распределения.
- **Критерий готовности:** Неактивные пользователи не попадают в результат генерации до повторной активации.
- **Зависимости:** Нет

### 4) Исправить скачивание Excel
- **Приоритет:** P1
- **Описание:** Исправить поломанный/нестабильный сценарий скачивания Excel-файла end-to-end.
- **Критерий готовности:** Сформированный Excel корректно скачивается у авторизованного пользователя в браузере.
- **Зависимости:** Нет

### 8) Запрос на обмен дежурствами
- **Приоритет:** P1
- **Описание:** Добавить запрос на обмен дежурствами с текстом уведомления: "Ревин Сергей, Иванов Владимир запрашивает обмен дежурствами с 12:00 на 14:00"; запретить обмен с самим собой.
- **Критерий готовности:** Пользователь не может создать обмен с самим собой; целевой сотрудник получает запрос/уведомление.
- **Зависимости:** Нет

### 11) Добавить утренние дежурства (07:00 и 08:00)
- **Приоритет:** P1
- **Описание:** Расширить расписание дежурств, добавив временные слоты 07:00 и 08:00.
- **Критерий готовности:** Генератор/UI/хранилище поддерживают новые слоты, и они видны в расписании и отчетах.
- **Зависимости:** Задача 14 (желательно предварительно проверить логику генерации)

### 14) Анализ справедливости генерации дежурств
- **Приоритет:** P1
- **Описание:** Проверить текущую логику генерации дежурств ("справедливый рандом") и убедиться, что нет скрытой эвристики/модельной логики.
- **Критерий готовности:** Алгоритм документирован с ограничениями и воспроизводимыми примерами.
- **Зависимости:** Нет

### 15) Аудит хранения паролей и Excel
- **Приоритет:** P1
- **Описание:** Проверить, как хранятся пароли и Excel-файлы; изменить логику хранения, если текущий подход слабый.
- **Критерий готовности:** Аудит безопасности завершен; необходимые изменения хранения внедрены и задокументированы.
- **Зависимости:** Нет

## P2 - Важно

### 5) Отображение текущего дежурного в реальном времени
- **Приоритет:** P2
- **Описание:** Показывать текущего дежурного в реальном времени без ручного обновления страницы.
- **Критерий готовности:** UI автоматически обновляет активного дежурного (polling или websocket) в заданный интервал.
- **Зависимости:** Нет

### 6) n8n: звуковое уведомление за 2 минуты
- **Приоритет:** P2
- **Описание:** Интегрировать n8n для звукового уведомления сотрудника, который начинает дежурство через 2 минуты.
- **Критерий готовности:** Workflow n8n получает событие и отправляет уведомление сотруднику следующего дежурства.
- **Зависимости:** Задача 5 (рекомендуется), настройка окружения/деплоя

### 7) Список сотрудников и редактирование на одном экране
- **Приоритет:** P2
- **Описание:** Улучшить экран сотрудников (логин, ФИО) и добавить редактирование на этой же странице.
- **Критерий готовности:** Админ может просматривать и редактировать логин/ФИО на одной странице управления.
- **Зависимости:** Задача 1

### 10) Исследование блокировки Push и задача на разблокировку
- **Приоритет:** P2
- **Описание:** Исследовать причины блокировки Push в браузере и подготовить операционный чек-лист для сотрудников по разблокировке.
- **Критерий готовности:** Причины задокументированы; опубликован понятный чек-лист действий для сотрудников.
- **Зависимости:** Нет

### 12) Обновление терминологии и формата времени
- **Приоритет:** P2
- **Описание:** Заменить "смена" на "дежурство" и показывать время как `12:00`, а не диапазоны вида `12-13` там, где это требуется.
- **Критерий готовности:** Терминология и формат времени обновлены в UI и артефактах без регрессий.
- **Зависимости:** Нет

### 13) Конструктор инструкции по авторизации инструментов
- **Приоритет:** P2
- **Описание:** Добавить функцию составления инструкции для сотрудника по авторизации во вспомогательных инструментах (УЗ, Bitrix, Zoom, почта) по шаблону Агудалина А.
- **Критерий готовности:** Пользователь выбирает инструменты и получает сгенерированную инструкцию на основе сохраненного шаблона.
- **Зависимости:** Нужен шаблон от Агудалина А

### 16) Инструкция по развертыванию и запрос ТЗ
- **Приоритет:** P2
- **Описание:** Описать шаги развертывания и подготовить явный запрос на формальное техническое задание (ТЗ).
- **Критерий готовности:** Есть воспроизводимая инструкция деплоя и подготовлен чек-лист/запрос на ТЗ.
- **Зависимости:** Нет

## P3 - Опционально/Улучшение

### 9) Позиция H1 на странице входа
- **Приоритет:** P3
- **Описание:** Переместить `h1` выше `loginForm` на странице входа.
- **Критерий готовности:** `h1` отображается визуально над формой логина в стандартной верстке.
- **Зависимости:** Нет
